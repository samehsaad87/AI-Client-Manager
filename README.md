# AI Client Manager

A lightweight AI automation tool for organizing client requests, classifying priority, drafting a response, and creating a follow-up report.

## Technologies
- Python
- OpenAI API
- python-dotenv

## Run
1. Copy `.env.example` to `.env` and add your API key.
2. `pip install -r requirements.txt`
3. `python main.py`

## Portfolio Focus
Demonstrates AI-assisted client operations, structured prompting, automation, and report generation.
